# Organization bundles

Bundles that install into an organization's headquarters. `luma-hq` adopts these
into a private hq repository.

One directory per bundle, each carrying a `bundle.md` at its root with a
`version`.

A bundle belongs here if applying it changes how an organization decides
things — how a standard is argued into existence, how a decision records its
reasoning and its re-open trigger, how boundaries between projects are drawn. If
it changes something inside a single repository, it belongs in
[`project/`](../project/) instead.

The test, when it is unclear: ask how many times the bundle is adopted. Once per
organization, or once per repository. Adopting an organization bundle into forty
repositories duplicates governance material that then drifts forty ways.
