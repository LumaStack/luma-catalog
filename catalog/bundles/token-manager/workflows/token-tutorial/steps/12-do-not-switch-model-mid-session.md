# Do not switch to a cheaper model to save money

This is the one worth actually remembering, because it is a mistake you make on
purpose while feeling responsible.

You are running low. You reach for `/model`, drop from Opus to Sonnet, and it
feels like the sensible move.

**It is the most expensive keystroke available to you.** The model is part of the
cache key, so switching means none of your history matches the cache any more and
the entire conversation gets reprocessed at full price. On a large context that
turns something like a ten-cent turn into a dollar turn — an immediate tenfold
charge, in exchange for a saving that would have arrived slowly.

Nothing warns you. It is completely invisible, and you did it to yourself while
trying to be careful.

**Changing your effort level does the same thing. So does turning on fast mode.**

If you are deep into a session and you genuinely want to be cheaper, the move is
`/clear` and start again on the model you want. Not a switch in place.
