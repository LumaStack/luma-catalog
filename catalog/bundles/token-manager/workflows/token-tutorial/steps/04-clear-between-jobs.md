# Clear between jobs

**The highest-leverage thing in this tutorial costs nothing and is five letters
long.** When you finish one job and start a different one, `/clear`.

Staying in the same thread because it is convenient is not free. That finished
conversation is not sitting quietly out of the way — it is being resent on every
message until the session ends. A session sitting at 80,000 tokens of history
drops to nothing the moment you clear.

**This is the one fix that is not a fraction of the others.** Everything else
here shrinks one component of your context. Clearing resets the base that all
those components are a percentage of. If most of your spend is re-reading
history, this is the only tool in the tutorial that deletes history.

**Rename before you clear.** Run `/rename` inside the session first, and
`/resume` can find it again by name if it turns out you needed it after all. You
are not throwing the work away. You are stopping the next job from carrying it.

One exception, and it is this session: **do not clear here.** Clearing is how this
tutorial ends — it is the last thing you will be asked to do — and doing it now
would take the tutorial with it. If you want to try it immediately, open a second
window and try it there.
