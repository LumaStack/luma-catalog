# Do not screenshot text

A picture is not cheaper than the words in it. A screenshot of your screen runs
to a couple of thousand tokens, and a 4K one closer to five thousand. That is a
great deal of text you could have pasted instead.

**So paste it.** It is cheaper, and there is a second reason that matters more
day to day: **your agent can edit text and cannot edit a picture.** Send an error
as a screenshot and the best it can do is read it back to you.

The exception is real and worth naming, so this does not become a superstition.
**When the layout is the thing you are asking about** — a rendered page, a chart,
a UI that looks wrong — the image carries information the text does not, and it
earns its cost.

For anything you could have selected and copied, it is a straight loss.
